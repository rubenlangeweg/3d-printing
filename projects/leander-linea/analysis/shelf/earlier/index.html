      How to read the bending comparison

      The colours show the additional response to the selected added load, with the same material and support assumptions for both models. A hotter colour means more movement or higher calculated stress; it does not show a tested failure threshold. The stepped surface is the actual analysis mesh. Surface stress colours average neighbouring elements; the peak readout refers to element stress before averaging. Fine edge stresses are not resolved by this grid.

      The comparison uses matched voxel grids. The published Z and X–Y stiffness values are used as two separate uniform isotropic sensitivity cases; directional behaviour is not simulated.

      The deformation control changes the displayed shape only. Numbers and colours use the selected added load. The verified 1 N, 2 GPa solution is scaled exactly within linear elasticity: movement × force × 2/E; stress × force. The original reference fields remain unchanged. At a fixed force, changing uniform stiffness changes movement but not stress in this model. The fixed displacement scale stays at 0–1 mm. Relative mode rescales to the largest displayed movement and can therefore show red even for a tiny displacement. Stress uses a separate relative scale. Neither scale indicates failure or a safe load. The animation cycles through the static deformation; it is not a dynamic simulation. Physical print tests are still needed to establish a useful load limit.
